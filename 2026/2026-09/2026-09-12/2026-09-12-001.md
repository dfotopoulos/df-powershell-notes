### Why the Error Occurred

The error occurs because of a **file name and path mismatch**:

1. **The script file is named
   [ `hyperv.ps1`](file:///C:/usr/src/df/powershell/df-powershell/devops/zeus/hyperv/hyperv.ps1)**,
   not `Manage-HyperVBackups.ps1`.
2. The file is located in:
    ```powershell
    C:\usr\src\df\powershell\df-powershell\devops\zeus\hyperv\hyperv.ps1
    ```
    If your current directory in PowerShell is not that folder, or if you call
    `.\Manage-HyperVBackups.ps1`, PowerShell cannot find it.
