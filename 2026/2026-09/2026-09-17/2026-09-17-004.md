### 3. Recommended Safety Fix for [

`hyperv.ps1`](file:///C:/usr/src/df/powershell/df-powershell/devops/zeus/hyperv/hyperv.ps1)

To prevent the script from ever attempting to delete the root Hyper-V host
directory again, lines 231–237 should be guarded:

```powershell
            $defaultHostPath = (Get-VMHost).VirtualMachinePath
            $isProtected = ($cfgPath -eq $defaultHostPath) -or
                    ($cfgPath -like "*\ProgramData\Microsoft\Windows\Hyper-V*") -or
                    ($cfgPath -in @("C:\", "C:\Windows", "C:\ProgramData"))

            if ($cfgPath -and (Test-Path $cfgPath) -and (-not $isProtected))
            {
                if ( $PSCmdlet.ShouldProcess($cfgPath, "Delete Configuration Directory"))
                {
                    Remove-Item -Path $cfgPath -Recurse -Force
                    Write-Host "Deleted config folder: $cfgPath" -ForegroundColor Red
                }
            }
```
