# 2026-09-20-006

## Summary

To install and enable **Microsoft PowerToys** for user **`df`** right now:

1. Inside your Remote Desktop session, press `Win + R`, type `powershell`, and
   press Enter.
2. Run this single command:

```powershell
winget install Microsoft.PowerToys --scope machine --accept-package-agreements --accept-source-agreements
```

3. Once the installation finishes, launch PowerToys immediately with:

```powershell
& "C:\Program Files\PowerToys\PowerToys.exe"
```

Because of `--scope machine`, PowerToys will now be permanently installed in
`C:\Program Files\PowerToys` and available in the Start Menu for both **`df`**
and **`Administrator`**.
