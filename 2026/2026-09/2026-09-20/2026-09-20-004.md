# 2026-09-20-004

## Summry

### Cause of the Error

In Windows SAM (`Microsoft.PowerShell.LocalAccounts`), the `Description`
parameter of `New-LocalUser` has a strict Windows API validation constraint:

- **Maximum Length:** **48 characters** (`[ValidateLength(0, 48)]`)
- The generated description string
  (`"Administrator provisioned via workstation setup script on ... "`) was **74
  characters**, causing `New-LocalUser` to reject it.
- Additionally, the previous `catch` block defaulted to re-prompting for a
  password on _any_ error, resulting in an infinite password prompt loop.

---

### Fix Applied

In
[Setup-Workstation.ps1](file:///C:/usr/src/df/powershell/df-powershell/windows/setup/Setup-Workstation.ps1):

1. **Shortened `Description` to 30 characters (well within the 48-char limit):**

    ```powershell
    Description = "Workstation Admin ($((Get-Date).ToString('yyyy-MM-dd')))"
    ```

2. **Targeted Exception Handling:** Refined the `catch` block so only genuine
   password/complexity policy violations trigger a password retry, while any
   other validation errors are surfaced immediately rather than trapping the
   user in a password prompt loop.

---

### Verification

Run the script in elevated PowerShell to complete the account creation:

```powershell
.\Setup-Workstation.ps1 -SkipPackages
```
