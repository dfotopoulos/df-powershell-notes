### Usage

#### 1. Interactive Full Run (in an elevated PowerShell prompt)

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
.\Setup-Workstation.ps1
```

#### 2. Dry Run Simulation (`-WhatIf`)

```powershell
.\Setup-Workstation.ps1 -WhatIf
```

#### 3. Install Software Packages Only

```powershell
.\Setup-Workstation.ps1 -SkipUserCreation -Silent
```

#### 4. Create Administrator Account Only

```powershell
.\Setup-Workstation.ps1 -SkipPackages
```
