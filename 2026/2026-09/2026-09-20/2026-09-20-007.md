# 2026-09-20-007

## Summary

### Cause of the Failure

```text
Found PowerShell [Microsoft.PowerShell] Version 7.6.6.0
The current system configuration does not support the installation of this package.
WARNING: winget completed with exit code -1978334957 for PowerShell.
```

1. **Error Code `0x8A150113` (`-1978334957`)**:
    - `0x8A150113` is WinGet's `APPINSTALLER_CLI_ERROR_INSTALL_NOT_SUPPORTED`.
    - The `Microsoft.PowerShell` package in `winget` uses an MSIX bundle
      (`PowerShell-7.6.6.msixbundle`).
    - On Windows Server (such as your EC2 instance `EC2AMAZ-1TKPUGB`),
      machine-wide AppX/MSIX provisioning (`--scope machine`) is blocked by
      system policy or not supported for this package.

2. **Why the Previous Script Didn't Recover**:
    - The script previously only retried without `--scope machine` on exit code
      `-1978335212` (`0x8A150014: NO_APPLICABLE_INSTALLER`).
    - Because Windows Server returned `-1978334957`, the fallback condition was
      bypassed and winget halted with a warning.

---

### Solution Applied in [Setup-Workstation.ps1](file:///C:/usr/src/df/powershell/df-powershell/windows/setup/Setup-Workstation.ps1#L195-L315)

1. **Universal Fallback on Machine-Scope Rejection**: Whenever `--scope machine`
   fails with **any** error (including `-1978334957` / `0x8A150113`), the script
   automatically falls back to standard scope:

    ```powershell
    if (-not $isSuccess) {
        Write-Host "[INFO] Machine-scope installation failed (exit code $exitCode). Retrying with default scope..." -ForegroundColor Yellow
        & $WingetPath install --exact --id $wingetId --source winget --accept-source-agreements --accept-package-agreements
    }
    ```

2. **Multi-Stage Fallbacks (Chocolatey & Official MSI Script)**: If `winget`
   fails completely on Windows Server (e.g. if MSIX / AppX services are
   disabled):
    - **Stage 2**: Automatically tries Chocolatey
      (`choco install powershell-core -y`).
    - **Stage 3**: For PowerShell specifically, runs Microsoft's official MSI
      installer script:
        ```powershell
        $installScript = Invoke-RestMethod -Uri 'https://aka.ms/install-powershell.ps1'
        & ([scriptblock]::Create($installScript)) -UseMSI -Quiet
        ```
        which directly installs `PowerShell-7.x.x-win-x64.msi` into
        `C:\Program Files\PowerShell\7\`.

3. **Smart Up-to-Date Detection**: Updated the pre-install check so that if
   `pwsh.exe` is already installed in `C:\Program Files\PowerShell\7\` and up to
   date, it is recognized and skipped (`[SKIP]`) on subsequent runs.
