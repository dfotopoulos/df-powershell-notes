## Summary

### 1. Skip Reinstallation for Packages Already at the Latest Version

#### Problem Analysis

Previously, the pre-check query used
`winget list --exact --id <id> --scope machine`. Because packages installed via
user-scope or default registration (e.g. PowerShell, Windows Terminal, LSD,
PowerToys) are not flagged as machine MSI/AppX packages by `winget list`, the
query returned no results. Consequently, the script treated them as uninstalled
and attempted reinstallation every time.

#### Implemented Fix in [Setup-Workstation.ps1](file:///C:/usr/src/df/powershell/df-powershell/windows/setup/Setup-Workstation.ps1#L195-L245)

1. **System-Wide Detection**: Updated the check to query all scopes:
    ```powershell
    $installedCheck = & $WingetPath list --exact --id $wingetId 2>$null
    ```
2. **Version & Update Header Analysis**:
    - Parses the table header from `winget list`.
    - If an update exists, WinGet outputs an `Available` column.
    - If **no `Available` column is present**, the package is **already
      installed in its latest version**; the script displays:
        ```text
        [SKIP] <PackageName> (<WingetId>) is already installed and up to date (v<Version>). Skipping.
        ```
        and returns immediately without calling `winget install`.
3. **Version String Normalization**: Handles version prefixes such as
   `> 17.14.41` cleanly with `.TrimStart('>').Trim()`.

#### Script Enhancements

2. **Programmatic Publisher Verification**: Before installing any package with a
   specified `Publisher`, the script executes a security check against the
   official manifest:
    ```powershell
    if ($Package.ContainsKey('Publisher')) {
        $showOutput = & $WingetPath show --exact --id $wingetId 2>$null
        # Validates that 'Publisher: Microsoft Corporation' matches expected publisher
        if ($actualPub -notlike "*$expectedPub*") {
            Write-Error "Security verification failed! Expected publisher '$expectedPub', but found '$actualPub'."
            return
        }
        Write-Host "[SECURITY] Verified publisher: '$actualPub' (matches expected '$expectedPub')." -ForegroundColor DarkCyan
    }
    ```
3. **IDE Path Registration**:
   `C:\Program Files\Microsoft Visual Studio\2022\Community\Common7\IDE`
   (`devenv.exe`) is automatically registered in the Machine Environment PATH
   via `Update-SystemEnvironmentPath`.
