### Usage Examples

```powershell
# List all Remote Desktop entries matching a domain regex pattern
.\windows\devops\mgmt-remote-desktop-registry-entries.ps1 -Pattern "df\.io"

# Filter by server IP subnet under 'Servers'
.\windows\devops\mgmt-remote-desktop-registry-entries.ps1 -Pattern "^192\.168\." -Scope Servers

# Filter by UsernameHint
.\windows\devops\mgmt-remote-desktop-registry-entries.ps1 -Pattern "pclab" -MatchField Username

# Preview removal of matching entries using -WhatIf
.\windows\devops\mgmt-remote-desktop-registry-entries.ps1 -Pattern "test\.df\.io" -Remove -WhatIf

# Export matching entries to JSON
.\windows\devops\mgmt-remote-desktop-registry-entries.ps1 -Pattern ".*" -Format Json -ExportPath "C:\temp\rdp-entries.json"

# Pipe multiple patterns
"earth", "138\.3" | .\windows\devops\mgmt-remote-desktop-registry-entries.ps1
```
