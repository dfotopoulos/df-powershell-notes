# 2026-09-14-003

## Summary

In Windows PowerShell 5.1, `if` is a statement rather than an expression, so
`(if ...)` fails inside parentheses unless using a subexpression `$()` or
assigning to a variable first. Also, the leading `S` in `Set-VMFirmware` got
clipped when pasted.

---

### Step 1: Check if `New-VM` already created the VM

Run:

```powershell
Get-VM -Name "se.windows.hyperv.zeus.df.io"
```

---

### Step 2: Apply the Setting

- **If the VM was already created**: Simply set Secure Boot (Windows default is
  `On`):

    ```powershell
    Set-VMFirmware -VMName "se.windows.hyperv.zeus.df.io" -EnableSecureBoot On
    ```

- **If the VM was NOT created yet** (or `New-VM` was interrupted): Run this
  clean block:
    ```powershell
    $vmName = "se.windows.hyperv.zeus.df.io"
    $vhdPath = "C:\var\hyperv\se\virtual-hard-disks\se-disk-001.vhdx"

    New-VM -Name $vmName -Generation $gen -MemoryStartupBytes $memStartup -VHDPath $vhdPath -SwitchName $switch
    Set-VMProcessor -VMName $vmName -Count $proc

    if ($dynamicMem) {
        Set-VMMemory -VMName $vmName -DynamicMemoryEnabled $true -MinimumBytes $memMin -MaximumBytes $memMax
    }

    $bootState = if ($secBoot -eq "Off") { "Off" } else { "On" }
    if ($gen -eq 2) {
        Set-VMFirmware -VMName $vmName -EnableSecureBoot $bootState
    }
    ```

---

### Step 3: Verify Checkpoints & Run Backup

Verify the checkpoint tree is now completely clean:

```powershell
Get-VMSnapshot -VMName "se.windows.hyperv.zeus.df.io"
```

_(Should return nothing)_

Then run the backup:

```powershell
.\hyperv.ps1 -Backup -VMNames "se.windows.hyperv.zeus.df.io" -BackupRoot "D:\var\hyper\backup"
```
